BILLAR EL BRUJO API - Railway + MySQL

Esta API se conecta a MySQL usando las variables de Railway:
MYSQL_URL
MYSQLHOST
MYSQLPORT
MYSQLDATABASE
MYSQLUSER
MYSQLPASSWORD

No escribas la contraseña dentro del código.
No compartas capturas donde se vea MYSQLPASSWORD.

PASOS PARA SUBIR A RAILWAY:
1. Crea un repositorio GitHub llamado BillarElBrujoApi.
2. Sube todos los archivos de esta carpeta.
3. En Railway, dentro del mismo proyecto donde está MySQL:
   New > GitHub Repository > BillarElBrujoApi.
4. En el servicio de la API, entra a Variables.
5. Agrega una referencia a las variables del servicio MySQL.
6. Deploy.
7. Abre la URL pública de la API.
8. Prueba:
   /health

Si /health responde ok=true, la API ya está conectada a MySQL.
